# Curio 家長端 App

測試網址：https://yiguo12.github.io/curio/

React + TypeScript 手機優先原型，包含餐前記錄與分析、用餐計時、餐後食量回顧、飲食與探索歷程。沿用原始品牌 logo、品牌色與最新大帽子水果 IP 靜態參考。

## 測試流程

先體驗示範 → 新增餐點 → 使用示範餐點或手動輸入 → 確認食物與份量 → 熱量分析 → 探索設定 → 開始用餐 → 暫停／繼續／結束 → 確認食用比例 → 儲存回顧。可再從紀錄編輯或刪除，同步重算每日攝取。

## 資料與示範服務

資料保存在每位測試者自己的瀏覽器 localStorage，沒有雲端或跨裝置同步。不要清除網站資料，否則紀錄會消失。AI 辨識、實體設備與投影尚未串接，照片只留在本機；示範餐點、熱量來源、建議規則與設備事件均明確標示。上傳照片不會假裝觸發 AI 辨識。

供餐量、已確認攝取與探索行為分開保存。攝取以供餐估算乘以家長確認的食用比例計算；未確認保持待確認，不直接計為已吃完。建議採示範分類規則與名稱相符忌口排除，不是完整過敏安全或個人化營養診斷。

## 原始碼與建置

`source/` 是完整開發專案，`index.html` 與 `assets/` 是目前上線的正式建置檔。

```sh
cd curio/source
npm install
npm test
npm run build
npm start
```

本機 http://127.0.0.1:5199/。開發模式使用 `npm run dev`。Vite base 為相對路徑，可部署在 /curio/ 子路徑。更新網站時，將 source/dist 的內容發佈至 curio/，保留 source/。

## 驗證

TypeScript 與正式建置通過；9 項核心測試涵蓋保存讀回、未確認食量、部分確認、份量重算、同餐不重複累加、刪除／孩子／台北日期篩選、暫停繼續與重新整理計時、事件來源及忌口排除。本次執行環境無可用瀏覽器控制，尚待實機手機／桌面畫面與完整點擊複驗。

後續待提供：正式食物辨識 API 與營養依據、硬體設備協定、最終故事與分層動畫資產。四分頁、localStorage、欄位及模擬 adapter 是交接規格本次補全的實作預設。
